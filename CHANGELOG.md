# Changelog

## 0.2.0 - first public test release
- Dialogue filter: show only choices you can do now; hold Shift to reveal all with requirements.
- Perk window: "unspent / earned" label; tooltips show cost and what is missing.
- Stats window: "Sanity details" breakdown.
- Foraging: protect the last harvest (override key), slow regrowth of partly used plants.
- Foraging: plants no longer reset just because you walked away and came back (`RespawnOnlyWhenDue`).
- Optional: gold weighs nothing.
- Optional cheat panel (off by default): searchable item give, coins, XP/levels, perks, character/world actions, and a Commands tab for every console command; minimize/close buttons; dark readable theme.
- Per-feature on/off switches, logging to BepInEx\LogOutput.log.
